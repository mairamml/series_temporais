#Instruções do Professor para o Trabalho

- Selecione um conjunto de dados de uma série temporal para as análises. Não serão aceitas séries artificiais, séries trabalhadas na disciplina ou conjuntos de dados simples disponibilizados em pacotes exclusivamente como exemplos didáticos. É permitido utilizar pacotes que realizem a coleta, o acesso ou a organização de dados reais provenientes de fontes externas.

- Realize a análise exploratória dos dados, incluindo a visualização da série temporal, estatísticas descritivas, análises de autocorrelação e autocorrelação parcial, além dos testes de hipótese necessários.

- Realize a modelagem dos dados utilizando os métodos estatísticos de previsão estudados
em aula. Separe os dados em conjuntos de treinamento e de teste, utilizando 80% dos
registros para treinamento e 20% para teste, considerando os seguintes limites máximos
para o conjunto de teste:
    – Dados anuais: 5 anos.
    – Dados trimestrais: 12 trimestres.
    – Dados mensais: 18 meses.
    – Dados semanais: 12 semanas.
    – Dados diários: 30 dias.

- Avalie o ajuste do modelo e o desempenho preditivo utilizando métricas apropriadas para séries temporais.

- Documente todo o processo, incluindo a descrição dos dados, as etapas da análise exploratória, a modelagem realizada, os modelos intermediários construídos até a obtenção do modelo final e a avaliação dos resultados.

- O trabalho final deve conter o conjunto de dados utilizado, o script elaborado para as análises e um relatório que documente todo o processo. O relatório deve seguir uma estrutura clara.

- Na etapa de modelagem, organize os modelos por tipo e analise cada grupo individualmente.
Por exemplo, identifique o melhor modelo de regressão e o melhor modelo ARIMA.

- Além disso, justifique a escolha de cada modelo e discuta suas limitações e possíveis melhorias.

- O aluno deverá especificar o período de dados utilizado na análise. Esse período deve ser suficientemente longo para permitir uma modelagem adequada e a avaliação do desempenho preditivo. Por exemplo, se a série temporal for mensal, recomenda-se utilizar de 3 a 5 anos de dados.
